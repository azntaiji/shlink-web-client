# Steelhead 4.9.0-beta.1

Beta release of the Steelhead fork of Shlink Web Client, based on upstream v4.8.1.

## QR code customization

- Dots and independent outer/inner eye styles, solid colors, and gradients.
- Background colors and gradients, with a reset control.
- Square and circular frames with custom colors and optional curved labels.
- Larger, scan-tested center logos with High error correction.
- A wider modal with two-column desktop settings and a mobile preview above settings.
- Enabled circular frames by default, with Dots Options and Frame expanded.

The client footer displays `v4.9.0-beta.1` and links to this fork's release. Server version links continue to point to Shlink.

For SVG exports imported into Figma, use a PNG center logo. QR styling is tested against representative scan cases; check final designs on your intended phones and at the intended display or print size.

## Building and publishing

Use Node.js 26. `node --run build:dist` uses the version in `package.json` and produces `dist/shlink-web-client_4.9.0-beta.1_dist.zip`. The `VERSION` environment variable can override the build version. Development and production use the same version source; version injection happens before asset hashing and PWA precaching.

After committing the release preparation, create an annotated `v4.9.0-beta.1` tag on that commit. Push the branch and that specific tag to origin. The tag workflow verifies the package version and publishes **Steelhead 4.9.0-beta.1** as a GitHub prerelease with the ZIP attached. It does not mark the beta as the latest stable release. The upstream Docker publishing workflow is skipped in this fork.

This file supplies the release notes. Future version tags use their matching notes file when present, otherwise GitHub-generated notes.
